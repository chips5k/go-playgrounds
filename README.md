# Go Playgrounds

Consolidated collection of Go projects, emulators, programming challenges, and algorithmic puzzle solutions.

## Projects

### [CHIP-8 Emulator](chip8-emulator) (2020)
CHIP-8 virtual machine and interpreter written in Go, implementing CPU cycle emulation, opcode decoding, timers, keypad input, and display rendering.

### [Gophercises](gophercises) (2020)
Solutions to the [Gophercises](https://gophercises.com/) Go exercises:
- **quiz**: Timed CLI quiz runner reading questions from CSV.
- **urlshort**: HTTP handler forwarding short URLs from YAML/JSON maps.
- **cyoa**: Choose Your Own Adventure web story adventure engine.
- **link**: HTML link parser extracting `href` and anchor text.

### [Advent of Code 2025](advent-of-code) (2025)
Solutions for Advent of Code programming puzzles written in idiomatic Go.
